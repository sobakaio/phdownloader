# Changelog

## 1.5.5

- Hardened native Save As cancellation, restored-job retries, terminal queue guards,
  persistent offscreen release alarms, and keyboard accessibility.
- Corrected HLS fallback filenames so MPEG-TS output is not mislabeled as MP4.

- Added branded orange extension icons at 16, 48, and 128 px.
- Scoped host permissions to PH and known CDN domains.
- Hardened queue restarts, cancellation, persistence, offscreen message ordering,
  MV3 listener compatibility, and cross-tab state handling.
- Improved popup readiness/status reporting and filename preview accuracy.
- Removed obsolete quality recommendation code and documented license, privacy,
  attribution, supported formats, and runtime requirements.
